# Your two inputs

Supply the AI with your timestamped UTF-8 script and narration audio. The AI handles the storyboard, props, characters, composition, QA and rendering. You do not need to write scene JSON.

Script format: one timed line per shot, for example `[00:04 – 00:10] বাংলা বাক্য।` SRT is also supported. Write names and numbers exactly as intended. Put chapter headings above their lines if desired. `ep02.md` contains the supplied example transcript.

The script and audio should describe the same narration. The AI must preserve timestamps, check audio duration, and inspect synchronization. Existing example timestamps are editorial estimates and have not been forced-aligned.
